01

エグゼクティブサマリー

背景

Niji DAOはBaseチェーン上にNouns型ガバナンスDAOを構築している。本レポートは13のブロックチェーンインデクサーを7つの次元（パフォーマンス、信頼性、DX、コスト、普及度、リスク、Baseチェーン対応）で評価し、最適なインデクシングソリューションを特定する。現在の業界は買収（PonderのMonad買収、SubsquidのRezolve AI買収）やサービス終了（Alchemy Subgraphs）による大幅な統合が進んでいる。

#1
Goldsky
無料 / マネージド / Graph互換
コスト、信頼性、使いやすさのバランスが最も良い。Graph互換のサブグラフ定義。無料StarterプランでDAO規模には十分。
#2
Envio HyperIndex
$70/月 / 最速 / TypeScript
技術的に最も優れ、The Graphの143倍高速なインデクシング。Uniswap V4の公式採用。V3テストフレームワークによるガバナンスデータの正確性検証。
#3
The Graph Studio
$0-1/月 / 最大のエコシステム
342K Xフォロワーと15,000以上のアクティブサブグラフを持つ最も成熟したサービス。イベント欠損や停止に関する既知の信頼性問題あり。

主な発見事項

  • ● The Graphにはデータ欠損やサブグラフ停止の問題が記録されており、Nouns DAOはPonderをセカンダリインデクサーとして追加した
  • ● PonderはMonad買収後に開発が実質停止している（2026年2月のコミットは1件のみ）
  • ● Envioはオープンソースではない（カスタムEULA、HyperSyncのソース非公開）が、技術的パフォーマンスは最高
  • ● Goldskyは3つのサブグラフワーカーとGraph互換定義を含む無料プランを提供
  • ● Base上のNouns型DAO（月間約1,860イベント）であれば、ほとんどの無料プランで十分

各サービスの特徴

評価対象13サービスの概要。分散型プロトコル、マネージドSaaS、OSSフレームワークなど、アーキテクチャの異なるサービスが混在している。

分散型 The Graph

ブロックチェーンインデクサーの事実上の標準。GRTトークンによる分散型ネットワークで、インデクサーがサブグラフをホストする。Uniswap、Aave等の主要DeFiプロトコルが採用。AssemblyScriptでサブグラフを記述するため学習コストがやや高い。15,000以上のアクティブサブグラフと最大のエコシステムを持つが、イベント欠損やサブグラフ停止といった信頼性の課題が報告されている。

SaaS Goldsky

Felicis・Dragonfly Capital等から$22M調達のマネージドインデクサー。The Graphのサブグラフ定義をそのまま利用でき、移行コストが極めて低い。Alchemy Subgraphs終了時の公式移行先に指定された。Mirror機能でClickHouse等への直接データパイプラインも提供。Polymarket、Zora、Optimism等が採用。無料Starterプランで3ワーカーまで利用可能。

ハイブリッド Envio HyperIndex

独自のHyperSyncデータレイヤーにより、The Graph比約400倍の圧倒的なインデックス速度を実現。TypeScriptでインデクサーを記述し、V3ではVitestベースのテストフレームワークを提供。Uniswap V4の公式インデクサーに採用された。ただしHyperSyncのソースコードは非公開（Custom EULA）で、ベンダーロックインのリスクがある。チーム規模は1〜10人と小さい。

OSS Ponder

TypeScriptネイティブのOSSインデクサーフレームワーク。開発者体験が最も優れており、ホットリロード・完全な型安全性・組み込みテストフレームワーク・GraphQL自動生成を備える。Nouns DAOがThe Graphの信頼性問題を補完するために採用。しかし2025年末にチームがMonad Foundationに買収され、2026年2月時点で開発がほぼ停止（月1コミット）。MITライセンスのためフォークは可能。

分散型 Subsquid (SQD)

SQD Networkという分散型データレイクを基盤とするインデクサー。TypeScript SDKによるバッチ処理モデルで、The Graph比約53倍高速。100以上のチェーンに対応し、EVM・Substrate・Solanaをサポート。2025年10月にRezolve AI（NASDAQ: RZLV）に約$10Mで買収され、AI転換リスクが懸念される。Apache-2.0 SDKは独立利用可能。

分散型 SubQuery

Polkadot/Substrateエコシステムから発祥し、現在は230以上のチェーンに対応する分散型インデクサー。SubQuery Networkによるトークンインセンティブモデルを採用。SDK 4.0でマルチスレッド対応とストアキャッシュレイヤーを導入し、パフォーマンスを向上。$16M調達、Discord約38Kメンバーの大規模コミュニティを持つ。

SaaS Ormi

Graph互換のマネージドサブグラフホスティング。sub-30msクエリレイテンシ、4,000 RPS、99.9% SLAを公約する高性能サービス。Pendle（$6B TVL）、Aura Finance等のDeFiプロトコルが採用。Google Cloudから$300K支援を受けている。チーム5人と小規模だが、$50B以上のTVLを支える実績がある。

OSS Rindexer

Rustで書かれた高速OSSインデクサー。ノーコード（YAML設定のみ）とカスタムRustハンドラーの両方に対応。Envio比では33倍低速だが、The Graph比12倍高速。ただしReorg処理が未実装、イベント欠損バグ(#264)、メモリリーク(#282)等の重大な品質問題があり、開発者1人のバスファクター1。本番環境には非推奨。

OSS Shovel

IndexSupplyが開発するGoベースの軽量OSSインデクサー。JSONの設定ファイルのみでEthereumデータをPostgreSQLに直接書き込む、シンプルなETLツール。コード不要のアプローチで導入が容易。Ethereum全履歴のNFT Transferイベントを5分以内にインデックスできる性能を持つ。GraphQLは非搭載で、SQLで直接クエリする設計。

補完 Shadow

他のインデクサーを補完する独自ツール。「Shadow Fork」により、既存のスマートコントラクトにカスタムイベントを追加し、オンチェーンで実行・インデックスできる。コントラクトを再デプロイせずにイベントを追加できるため、既存プロトコルの分析に有用。P95 5秒未満のレイテンシでリアルタイム処理。単体インデクサーではなく、他サービスとの併用が前提。

SaaS Sentio

インデクシングだけでなく、モニタリング・アラート・分析ダッシュボードを統合した包括的なWeb3データプラットフォーム。大規模並列処理により従来比最大100倍高速なインデックスを実現。EVM、Solana、Aptos等マルチチェーン対応。TypeScriptでプロセッサを記述し、SQLベースのクエリを提供。オブザーバビリティツールとしての側面が強い。

SaaS Flair

リアルタイムストリーム処理に特化したインデクサー。集計・ロールアップ等のデータ変換をストリーミングで実行し、水平スケール可能なアーキテクチャ。TypeScriptでハンドラーを記述。定量的なパフォーマンスデータは公開されていないが、並列・分散処理パラダイムによる高スケーラビリティを謳っている。

終了 Alchemy Subgraphs

Alchemyが提供していたマネージドサブグラフホスティングサービス。2025年12月にサービスを終了し、Goldskyへの公式移行パスを提供。この終了がGoldskyの市場ポジション強化につながった。

リスク分析

Service リスク要因 深刻度 軽減策
The Graph イベント欠損 / サブグラフ停止 高 デュアルインデクサー構成（例: + Ponder）
Hosted Service終了（2026年） 中 Studio / Goldskyへ移行
Goldsky プロプライエタリ / ベンダーロックイン 中 Graph互換サブグラフは移植可能
Envio プロプライエタリライセンス、HyperSyncロックイン 高 RPCフォールバック可能（2000倍低速）
小規模チーム（1〜10人） 中 成長中、Uniswap V4の採用が有効性を証明
Ponder 開発実質停止（Monad買収） 致命的 MITライセンスによりフォーク可能
サイレント同期停止バグ (#2264、未解決) 高 外部モニタリングが必要
Subsquid Rezolve AI買収、AI転換リスク 高 Apache-2.0 SDKにより独立利用可能
Rindexer バスファクター1、イベント欠損バグ (#264) 致命的 本番環境には非推奨
Ormi 小規模チーム（5人）、最小限の資金 中 $50B以上のTVL顧客基盤が有効性を証明

The Graph の既知の信頼性問題

  • • 異なるブロック間でのイベント欠損 (graph-node #3891)
  • • 誤ったリオーグ検出によるサブグラフの恒久的停止 (#5586)
  • • Uniswapサブグラフの本番障害（ポストモーテム文書化済み）
  • • 回復不能な非決定的エラー (#3708, #5607)
  • • PostgreSQLインデックスロックによるメモリ枯渇 (#764)
  • • Nouns DAOはこれらのリスク軽減のためPonderをセカンダリインデクサーとして追加

Niji DAOへの推奨

1
第1推奨: Goldsky（無料Starterプラン）

Graph互換のサブグラフ定義により移植性を確保。無料枠でDAO規模のイベント量に十分対応。マネージドサービスにより運用負荷をゼロに。Alchemyの公式移行先として安定性が実証済み。

2
代替案: Envio HyperIndex（$70/月）

最高のパフォーマンスとVitestベースのテストを重視する場合に最適。自動テストによるガバナンスデータの正確性確保に優れる。TypeScriptネイティブの開発体験。

3
フォールバック: The Graph Studio（$0-1/月）

最大のエコシステムと豊富なドキュメント・コミュニティサポート。既知の信頼性問題は外部モニタリングで軽減すべき。重要なガバナンスデータにはデュアルインデクサー構成を検討。
